# Pulse Visuals Clone — Minecraft 1.21.4

Оригинальный клиентский Fabric-мод с визуальными функциями в духе современных PvP Visuals-модов.

## Что уже есть
- Hit Particles (crit particles при ударе)
- Target HUD с HP-баром
- Custom Crosshair
- Low HP screen effect
- Переключение всех функций
- GUI настроек
- Горячие клавиши: Right Shift — меню, O — общий toggle

## Сборка
Требуется Java 21.

1. Установи Fabric Loader и Fabric API для Minecraft 1.21.4.
2. Открой папку проекта в IntelliJ IDEA / VS Code.
3. Запусти `./gradlew build`.
4. Готовый JAR будет в `build/libs/`.

Это самостоятельная реализация: она не содержит код, ассеты или закрытые материалы Pulse Visuals.
